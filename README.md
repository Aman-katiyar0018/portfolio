## 🌐 How to Upload to GitHub & Deploy to GitHub Pages

1. Open PowerShell in this `Portfolio` folder.
2. Check your git repository status:
   ```powershell
   git status
   ```
3. Add and commit all files:
   ```powershell
   git add .
   git commit -m "feat: complete developer portfolio with internship experience, projects, and certifications"
   ```
4. Set branch to `main`:
   ```powershell
   git branch -M main
   ```
5. Link to your GitHub repository:
   ```powershell
   git remote add origin https://github.com/Aman-katiyar0018/portfolio.git
   ```
   *(If remote origin already exists, use `git remote set-url origin https://github.com/Aman-katiyar0018/portfolio.git`)*
6. Push to GitHub:
   ```powershell
   git push -u origin main
   ```
7. On your GitHub repository page:
   - Go to **Settings** → **Pages**
   - Under **Build and deployment**, select source: **Deploy from a branch**
   - Select Branch: **`main`**, Folder: **`/ (root)`**
   - Click **Save**
   - Your portfolio will be live at: **`https://aman-katiyar0018.github.io/portfolio/`**
